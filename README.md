# bot-cafe ☕

Bot que monitora promoções de café, cafeteiras e acessórios (Promobit, Gatry e canais de promoção no Telegram), compara com o menor preço do Buscapé e avisa no WhatsApp via CallMeBot.

- Ajustes: edite `config.json` (palavras-chave, exclusões, lista de desejos, `abaixo_do_mercado_pct`).
- Roda sozinho a cada ~10 minutos pelo GitHub Actions.
- Precisa dos secrets `WHATSAPP_PHONE` e `CALLMEBOT_APIKEY`.
